# Zendesk Help Desk Ticketing Lab

## Project Overview
In this lab, I set up a complete help desk environment using **Zendesk** to practice how IT tickets are handled from start to finish. My goal was to act as a Support Technician and manage a variety of technical issues, ensuring each one was tracked, organized, and solved efficiently. 

I focused on the entire "life" of a ticket: receiving the initial request, assigning priority levels, and communicating with users. By using tools like tags and status categories, I made sure the system stayed organized so that no technical problem was overlooked.

## What I Did
* **Ticket Triage:** I reviewed incoming requests to decide how urgent they were and assigned them to the correct support groups.
* **Technical Troubleshooting:** I documented steps to fix common IT issues, such as HDMI display problems and scheduled computer updates.
* **Workflow Management:** I used "Open," "Pending," and "Solved" statuses to keep track of work in progress.
* **User Communication:** I wrote clear, simple replies to users to explain how their problems were fixed and when their tickets would be closed.

## Tools Used
* **Ticketing System:** Zendesk
* **Methodology:** Incident Management & Customer Service Best Practices

## Final Results
By the end of this lab, I successfully cleared the ticket queue and resolved all open incidents. This project shows my ability to use professional support software, manage my time, and provide helpful technical assistance to users.

# [TICKET #1]: HDMI unplugged from users computer, monitor had no display

## Project Overview
In this project, I managed a technical support ticket from start to finish using a professional ticketing system. I identified a hardware connectivity issue, resolved the problem for the user, and documented the process to ensure clear communication and record-keeping.

## What I Did
1. **Identified the Issue:** A user reported that their computer had no display. 
2. **Physical Inspection:** I checked the physical connections and found that the HDMI cable was unplugged from the PC.
3. **Resolution:** I securely plugged the HDMI cable back into the display port on the computer.
4. **Verification:** I confirmed that the monitor was receiving a signal and showing a picture again.
5. **Documentation:** I updated the support ticket with a clear explanation for the user and closed the case as "Solved."
